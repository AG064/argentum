# Argentum v0.0.8

v0.0.8 is the first non-alpha cut of the Argentum workspace. It includes the desktop
application that 0.0.8-alpha shipped, **plus the first-party Argentum Android app**
(Kotlin + Jetpack Compose, liquid-glass theme, onboarding, full release APK pipeline).

## Install

### Desktop

- Windows: `argentum-v0.0.8-win-x64-setup.exe` (NSIS) and `argentum-v0.0.8-win-x64.msi`
- macOS: `argentum-v0.0.8-macos-x64.dmg` (Intel) and `argentum-v0.0.8-macos-arm64.dmg` (Apple Silicon)
- Linux: `argentum-v0.0.8-linux-x64.AppImage`, `.deb`, `.rpm`
- Portable CLI: `argentum-v0.0.8-linux-x64`, `argentum-cli-v0.0.8-win-x64.exe`,
  `argentum-v0.0.8-macos-x64`

### Android

- `argentum-v0.0.8-android.apk` — universal release APK
- Sideload: download, allow "Install unknown apps" for your file manager, open the APK
- See `docs/ANDROID_BUILD.md` for build instructions, signing, and Play Store notes

## What's New in 0.0.8

### Argentum Android App

- **Kotlin + Jetpack Compose**, Material 3, `minSdk 26` / `targetSdk 34`
- **Liquid-glass Argentum theme** — silver/crimson palette, blurred surfaces, animated
  highlights, and a real glass refraction effect on cards and the bottom nav
- **Onboarding flow** — welcome screen → provider picker (MiniMax, OpenAI, local
  llama.cpp) → API key entry with secure storage → finish. The whole flow is persisted
  in DataStore and only runs once per device
- **AnimatedButton** — press scale, haptics, focus ring for keyboard / TalkBack users
- **Chat screen** — conversation list, streaming-friendly composer, agent-aware
  (uses the same provider stack as the desktop gateway)
- **Settings screen** — dark/light theme, accent color, version, link to docs
- **Agents screen** — view and switch between configured agents
- **Tests** — unit tests for `ChatViewModel`, `SettingsViewModel`, `AgentsViewModel`

### Release Pipeline

- The `release.yml` workflow now produces **both the desktop artifacts and the Android
  release APK** on every `v*` tag push
- The APK is signed with a CI-managed keystore. Sideload-ready out of the box. Replace
  with your own keystore before Play Store submission (see `docs/ANDROID_BUILD.md`)

### Versioning

- `0.0.8-alpha` → `0.0.8` (non-alpha)
- Android `versionName` / `versionCode` now mirror the Argentum version (`0.0.8` / `8`)
- Tauri Windows WiX version aligned with the product version

## Stable Providers

- **MiniMax** — stable through API key auth, default in onboarding
- **OpenAI / ChatGPT** — stable through API key auth and ChatGPT/Codex browser-account flow
- **Argentum llama.cpp local server** — stable for local GGUF model execution; optional
  installer-time binary install, plus in-app install via the Local Server screen

## Testing Providers

Anthropic Claude, Google Gemini, OpenRouter, NVIDIA, Groq, external Ollama/local
endpoints, and Custom endpoint remain in testing state. They can be selected and
tested, but they are not promoted as stable desktop routes yet.

## Hardware Requirements

| Level       | Requirement                                                                                                                                               |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Minimum     | 64-bit CPU, 4 GB RAM, 500 MB free disk space, working system webview, internet access for hosted providers.                                               |
| Recommended | 4-core CPU, 8 GB RAM, 1 GB free disk space, stable broadband, and an SSD-backed workspace.                                                                |
| Gateway     | Localhost port `3000` available by default. Provider/network access still depends on workspace configuration and approval.                                |
| Android     | Android 8.0+ (API 26+), 200 MB free storage, network access for hosted providers. Sideload requires enabling "Install unknown apps" for the file manager. |
| Providers   | ChatGPT/OpenAI usage follows the selected account or API plan. MiniMax Token Plan usage and reset cadence are visible where the provider exposes them.    |

## Known Issues

- The release APK is signed with a CI-managed keystore by default. This is fine for
  sideloading and personal use; replace with your own keystore (see
  `docs/ANDROID_BUILD.md`) before publishing to the Play Store.
- The Android `Chat` screen talks to the local agent over HTTP on the host machine.
  Out of the box this only works on emulators and rooted/debuggable devices; see the
  Android docs for the secure tunneling options.

## Upgrade Notes

- Coming from `0.0.8-alpha`: no data migration needed. The Android app is new — no
  prior version to upgrade from. On first launch the onboarding flow runs once.
- Coming from `0.0.7` or earlier: the workspace path on Windows moved from the
  hard-coded `LOCALAPPDATA` to the Tauri default. The app will offer to migrate any
  existing workspace on first run.
