# NEXT01: governed extension and browser foundations

Ready-to-send implementation brief, not activated by RELEASE01.

Start from the reviewed native CLI source identity and RC evidence. Preserve
historical releases/stores and accepted coding, edit, verification, accounting,
recovery and provider behavior. Do not restart benchmark repairs or copy another
application's proprietary plugins, credentials or sessions.

Deliver one substantial vertical milestone: governed portable plugin/skill and
MCP integration, then a complete browser-assisted local development workflow.
Inspect existing `argentum-harness`, lifecycle, local skills, instructions, jobs,
policy, secure credential and result paths first. Use historical Node modules
only as reference. Keep adapters optional and disabled until owner-authorized.

## Implementation

1. Inventory portable Agent Plugins manifests, skills and MCP dependencies;
   explicitly classify unsupported host hooks, registered apps and presentation
   extensions. Preserve source/revision/license/integrity and reject ambiguity.
2. Use an explicitly pinned current MCP spec/SDK profile. Implement bounded
   discovery and tool/resource transport with safe credential scope, issuer/origin
   checks, revocation, cancellation and honest unavailable states. MCP is not a
   plugin sandbox or installation system. Do not enable remote commands from
   manifest text, model output or annotations alone.
3. Reuse the native lifecycle/authority broker for install/update/activation,
   capability and destination review, readiness, retirement and recovery. Deny
   excess filesystem/network/process requests; no arbitrary model shell or
   implicit approval. Treat extension content/results as untrusted.
4. Integrate a version-pinned maintained Playwright adapter, not a browser engine.
   Offer isolated profiles by default and explicit owner-authorized persistent
   profiles for sign-in. Never import another application's cookies/session state.
   Bind browser/context/tab identities and stale observations; bound preview
   servers, navigation, downloads/uploads, screenshot/DOM/log capture and actions.
5. Provide normal CLI model-facing observation/action/result flow for local web
   preview, interaction, screenshot review and console/network diagnosis. Browser
   results must return to the same policy/accounting/cancellation system. No
   second ungoverned task runtime. Source verification and rendered result remain
   separate evidence.

## End-to-end acceptance

Use disposable projects and licensed public controls. First install a synthetic
plugin, discover/invoke a scoped tool in a normal coding task, cancel/disable it
mid-call, restart and demonstrate revoked/stale handles denied without leaks.
Test malformed manifest/schema/oversized responses, destination escalation,
credential rejection and teardown recovery. Registering a tool name is not pass.

Then deliver an unseen small local web contribution through Argentum: inspect
source, implement through normal guarded tools, run its verifier, launch preview,
inspect actual DOM/screenshot/console/network state, exercise interactions, find
and repair a real defect, and report source plus rendered acceptance separately.
Include redirects, popups, stale tab identity, downloads, focus/context switching
and cancellation negative controls. A static screenshot or a running server alone
does not establish a completed browser workflow.

For a signed-in workflow, use the owner's explicit supported ceremony once when
necessary; prepare a consolidated action rather than repeated routine setup.
Keep account secrets out of prompts, screenshots, logs, public evidence and
extension exports. Distinguish an owner security approval from avoidable repair
coordination. Broader desktop/UI Automation remains the following milestone.

Reuse established provider access, compiler lanes and evidence. This brief does
not set a live allowance: obtain a finite explicit allowance before live work,

actual acceptance, preservation, consumption and precise remaining limitations.
Do not claim Codex replacement or superiority until later unseen representative
