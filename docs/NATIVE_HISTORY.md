# Implementation provenance

The native Cargo workspace supersedes the historical TypeScript/Node/Tauri
root product. Earlier versions remain in Git history and versioned releases;
their browser, plugin and channel modules are not advertised as native features.

The native foundation added typed commands/events, bounded provider adapters,
project policy, explicit authority, exact mutation journals, verification and
recoverable process/store ownership. Later accepted work added search-to-read
selections, CRLF-safe edits, provider continuation, public-contract Rust checks,
bounded failure diagnostics and historical change pagination.

These implementation slices were qualified with source-bound unit tests,
credential-free CLI controls and separately retained historical live evidence.
Earlier failed attempts remain failures. Exposed benchmark results are not
unseen-task reliability evidence. Some deliveries required supervisor review,
configuration/recovery or authored infrastructure.

bounded historical change-pagination contribution, with review feedback and
separate supervisor accounting/transport repair. Passing declared verification
does not convert it into an unassisted autonomy claim.
