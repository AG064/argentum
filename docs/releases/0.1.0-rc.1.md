# Native Windows CLI 0.1.0-rc.1

Status: release candidate preparation and offline qualification in progress.
This is a draft native source transition, not a public release or a daily
Codex-replacement acceptance. No tag, signing, default-branch merge or package
publication is performed by the packaging/CI scripts.

The accepted native source is carried forward with release metadata, formatting,
portable public test controls and sanitized documentation/tooling. Product
runtime behavior is not deliberately rewritten. MILESTONE01 remains assisted
delivery. No new provider generation, catalogue, model download or benchmark
attempt is part of RELEASE01.

Current verified gate: locked offline Windows check of all workspace targets.
Test, strict lint, dependency policy, source review, clean-checkout package and
exact-executable controls are recorded here after they finish. Missing evidence
will remain explicitly unverified, not a passing status.

The package is Windows x64 CLI only, with source commit/tree, executable hash,
toolchain/build arguments, dependency notices and SHA256SUMS. It contains no
store, credential, model, Slint UI or optional llama.cpp runtime. Starting from a
fresh checkout can populate ordinary pinned Cargo dependencies normally; an
earlier offline-cache pass is not a claim that dependencies were vendored.

The project acknowledgement-bearing license is retained and inherited through
Cargo `license-file`. Public source remains subject to that exact text. UI and
Android distribution/licensing/device/signing gates remain separate.

Before public release: review the draft transition and qualified limitations,
then make one explicit maintainer release decision. No owner adoption or new
benchmark run is required as a completion step for release preparation.
