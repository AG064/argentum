## Source transition and review

The accepted native implementation was reconciled into one clean native root;
the older TypeScript product stays in its historical revisions/releases. All
recorded accepted source inputs and prior executable/index identities were
preserved in their original checkouts. Private stores, campaign evidence,
graders, prompts and downloaded/build payloads are excluded from the public tree.
Permanent controls use public synthetic inputs rather than private postimages.

Representative parent-only security and diff reviews cover authority, credential,
provider continuation, scoped grant, file/process and packaging boundaries.
Coverage is explicitly partial, not certification or an exhaustive no-vulnerability
claim. The reports retain their initial immutable revision and distinguish the
later reviewed/patched successor delta. Every outgoing commit/tree receives a
separate privacy/size inspection before publication.

## Qualified limits and final decision

Local runtime evidence is Windows build 26100. The CLI imports VCRUNTIME140 and
Universal CRT components; an installed x64 Microsoft Visual C++ runtime is
required and is not bundled. No pristine-VM/minimum-Windows-version or installer
acceptance is claimed. The artifact is unsigned; SmartScreen/signing remain
separate distribution considerations. Other platforms, native UI and Android
need their own release/device/visual/license gates.

The acknowledgement-bearing first-party license was deliberately retained;
Cargo now references the exact file instead of claiming unmodified MIT. The
two exact upstream dual-licensed dependencies that omit text are packaged with
their declared Apache option and pinned full terms/declaration metadata.

After reviewing this draft source transition and qualified evidence, the
maintainer can make one deliberate merge/public-release/cutover decision.
Nothing is published automatically, and owner adoption is not a completion step.
The [two-track roadmap](../../ROADMAP.md) and
[next extension/browser milestone](../NEXT_EXTENSION_BROWSER_MILESTONE.md)
remain separate from this CLI release gate.
