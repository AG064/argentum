# Argentum v0.0.9

v0.0.9 adds the **in-app OpenClaw migration flow** — import skills, memory, SOUL.md,
workspace files, credentials, and config directly from `~/.openclaw/` without leaving
the app — plus internationalization (English + Estonian), the thinking mode wired to all
LLM providers, and a rebuilt skills catalog with a Built-in tab.

## Install

### Desktop

- Windows: `argentum-v0.0.9-win-x64-setup.exe` (NSIS) and `argentum-v0.0.9-win-x64.msi`
- macOS: `argentum-v0.0.9-macos-x64.dmg` (Intel) and `argentum-v0.0.9-macos-arm64.dmg` (Apple Silicon)
- Linux: `argentum-v0.0.9-linux-x64.AppImage`, `.deb`, `.rpm`
- Portable CLI: `argentum-v0.0.9-linux-x64`, `argentum-cli-v0.0.9-win-x64.exe`,
  `argentum-v0.0.9-macos-x64`

### Android

- `argentum-v0.0.9-android.apk` — universal release APK
- Sideload: download, allow "Install unknown apps" for your file manager, open the APK
- See `docs/ANDROID_BUILD.md` for build instructions, signing, and Play Store notes

## What's New in 0.0.9

### Internationalization (i18n)

Argentum is now fully translatable:
- **Language picker** in Settings → Appearance (English, Eesti / Estonian)
- **Full i18n infrastructure** — `t()` translation function, `setLocale`/`getLocale`, `formatNumber`, `formatDate`, `formatRelativeTime`, `textDirection`
- **RTL-ready** — `dir` attribute on `<html>`, CSS logical properties throughout
- Language preference persisted via localStorage

### Thinking Mode Wired to All Providers

The thinking level setting (fast/balanced/deep) in the chat composer and Settings → Context is now passed to every LLM API:

- **Anthropic** (Claude Sonnet 4, Opus 4): `thinking: { type: "adaptive", budget_tokens: N }` with `anthropic-version: 2025-01-01`; budget maps fast → 1,024, balanced → 8,000, deep → 32,000 tokens
- **Codex** (browser-account OAuth): `reasoning: { effort: "low|medium|high" }`
- **OpenAI** (GPT-5 family): `reasoning_effort: "low|medium|high"`

Settings UI shows a green "thinking mode supported" note for reasoning-capable models. New models: `claude-sonnet-4-20250514` and `claude-opus-4-20250514`.

### Skills Catalog — Built-in Tab

A new "Built-in" tab in Settings → Skills renders first by default, showing the four bundled skills (docx, pdf, pptx, xlsx) with a distinct "Built-in" badge and no install/GitHub button. Skill sources are now typed: `argentum` (bundled), `anthropic`, `codex`, `installed`, `testing`.

### In-App OpenClaw Migration

- **Automatic detection on first run** — after selecting a workspace, Argentum scans
  `~/.openclaw/` and shows a migration card in the onboarding flow if found
- **Settings → Migration** — accessible anytime after setup; rescan, preview, and
  re-import without re-running onboarding
- **Full item coverage** — imports skills, long-term memory (MEMORY.md), user profile
  (USER.md), SOUL.md persona, workspace files, memory database, Telegram bot
  credentials, and OpenClaw config (provider, model, MCP servers)
- **Per-item conflict handling** — text files append to existing content; directories
  merge skill-by-skill; binary files (memory.db) copy directly
- **Hermes → Argentum migration** is planned for v0.1.0

### CI / Release Pipeline

- **Fixed desktop-release 404** — `attach-installers` step now gracefully skips
  cleanup when the git tag has no matching GitHub release (handles lightweight
  tags used for CI-only builds)
- **Dependency audit** — `ws` and `openai` packages updated to patch known vulnerabilities

### Versioning

- v0.0.8 → v0.0.9
- Android `versionName` / `versionCode` now mirror the Argentum version (`0.0.9` / `9`)
- Tauri Windows WiX version aligned with the product version

## Upgrade Notes

- Coming from `0.0.8` or earlier: the workspace path structure is unchanged. On first
  launch, the migration card appears automatically if `~/.openclaw/` exists on your system.
- Migration can be run again at any time from **Settings → Migration**.
