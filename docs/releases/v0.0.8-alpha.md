# Argentum v0.0.8-alpha

v0.0.8-alpha v0.0.8-alpha is a Linux workspace path fix release. It keeps the security cleanup already merged into `development`, then focuses on the parts of the app people touch first: chat, onboarding, provider setup, Telegram session handling, and app-visible diagnostics.

This release also adds the first stable Argentum llama.cpp local server path. The Windows setup executable can install the local server binaries when selected in the installer, while the default install remains lightweight. Users who skip it can install the server later from the Local Server capability inside Argentum.

## Install

Recommended Windows downloads:

- `Argentum_0.0.7_x64-setup.exe` - Windows desktop setup executable.
- `Argentum_0.0.7_x64_en-US.msi` - direct Windows Installer package.

Linux and macOS remain source-supported targets in this release. Packaged AppImage, DEB, RPM, and DMG assets should be produced by release automation before they are advertised as downloadable files.

## Stable Providers

- ChatGPT / OpenAI is the stable OpenAI route for desktop chat through API key auth and the ChatGPT/Codex browser-account flow where available.
- MiniMax is stable through API key auth. Token Plan usage checks and M2.7 guidance are wired into Diagnostics and runtime context where MiniMax exposes the data.
- Argentum llama.cpp local server is stable for local GGUF model execution through Argentum's local server controls. It supports optional installer-time binary installation and in-app installation.

## Testing Providers

Anthropic Claude, Google Gemini, OpenRouter, NVIDIA, Groq, external Ollama/local endpoints, and Custom endpoint remain in testing state. They can be selected and tested, but they are not promoted as stable desktop routes yet.

## Changelog

- Chat now uses a cleaner developer-workspace layout with a calmer conversation rail, a fixed composer, a context indicator, and a right inspector for session data.
- Empty chats are easier to recognize. The first screen now gives a clear fresh-start state instead of looking like a half-loaded thread.
- Onboarding now has a dedicated controller for step changes, validation, progress persistence, and completion.
- Provider selection starts empty unless a saved config exists. Beginner, Intermediate, and Expert choices also write to real onboarding state.
- Continue, Back, provider selection, model selection, and Finish all route through the same onboarding controller.
- Blocked onboarding now shows a visible reason. It no longer fails silently.
- Dense onboarding details were moved into foldable sections and tooltips so the wizard keeps a stable size without hiding required controls.
- Streaming reasoning output is parsed and stored separately from the normal assistant answer.
- Telegram messages can create or attach to Argentum sessions and route through the same session pipeline as desktop chat.
- Local Server now has a dedicated install action and a Windows setup checkbox for users who want Argentum to install llama.cpp binaries during setup.
- The installer no longer bundles llama.cpp unless that optional setup checkbox is selected.
- Monaspace Krypton is bundled for the desktop UI.
- The production npm audit chain has been updated to patched Express, body-parser, and qs versions.
- The desktop app now has app knowledge and workspace/agent architecture notes for safer app-aware context.
- Version metadata is synchronized to v0.0.8-alpha across Node, Tauri, Cargo, README, and release notes.

## Supported OS

| Platform | Current support         | Assets                                 | Runtime notes                                                                                                                       |
| -------- | ----------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Windows  | Windows 10/11 x64       | `.exe`, `.msi`                         | Uses Microsoft Edge WebView2. Windows 11 includes it; Windows 10 1803+ usually has it, and the installer can install it if missing. |
| Linux    | Source-supported target | Release packages pending CI automation | Intended for Ubuntu 22.04+ and similar desktop distributions with WebKitGTK 4.1.                                                    |
| macOS    | Source-supported target | Release packages pending CI automation | Intended for macOS 10.15+ on Intel and Apple Silicon. Uses system WKWebView.                                                        |

## Hardware Requirements

| Level       | Requirement                                                                                                                                            |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Minimum     | 64-bit CPU, 4 GB RAM, 500 MB free disk space, working system webview, internet access for hosted providers.                                            |
| Recommended | 4-core CPU, 8 GB RAM, 1 GB free disk space, stable broadband, and an SSD-backed workspace.                                                             |
| Gateway     | Localhost port `3000` available by default. Provider/network access still depends on workspace configuration and approval.                             |
| Providers   | ChatGPT/OpenAI usage follows the selected account or API plan. MiniMax Token Plan usage and reset cadence are visible where the provider exposes them. |
