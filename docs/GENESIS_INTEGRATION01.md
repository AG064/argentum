## Qualification and review

The required final matrix is formatting/whitespace, workspace/all-target check
and strict lint, the existing named optional profiles, current dependency and
license/source policy, scoped outgoing-source review, actual installed Node
and legacy Rust verifier controls, native lifecycle/authority negatives and
relevant credential-free packaged extension/artifact/process controls.

Use disposable fixtures and explicit selected executable/worker paths. Owner
stores are not opened writable or migrated for integration evidence. Build the
final recorded source in a clean checkout and a task-owned clean target under
the serial compiler lane; dependency-cache reuse is not reuse of an old binary.
Verify package/extraction members and outside-checkout/spaced/non-ASCII launch.

The existing workflow qualifies pushes to `codex/**`; a dependent draft against
another native feature branch is not covered by its development-only PR trigger.
Local and hosted results, pending/failed/skipped gates, inherited evidence and
newly executed controls must remain separately labelled in the review handover.

Integration delivery grants no new live allowance. No completed workflow is
rerun, no unused capacity transfers and no new model task starts from this
record. Daily-use reliability, general computer use, Google/account acceptance,
merge, signing, tags, publication and release certification remain excluded.
