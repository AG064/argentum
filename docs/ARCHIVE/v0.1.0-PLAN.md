## 3. Компоненты для v0.0.7

### 3.1 llama.cpp Integration (НОВОЕ)

```
src/providers/llama-cpp/
├── index.ts           # LlamaCppProvider implements LLMProvider interface
├── server-manager.ts  # Spawn/manage llama-server process
├── model-downloader.ts # Download from HuggingFace/GGUF
├── model-catalogue.ts  # Curated list: 0.6B → 700B, system recommendations
└── types.ts           # LlamaCppConfig, ModelInfo
```

**Что делает:**

- Download и запуск llama-server (или llama.cpp binary)
- Подключение через OpenAI-compatible endpoint (`/v1/chat/completions`)
- Model catalog: авторские рекомендации какую модель ставить под какую систему
- TPS optimization, context size tuning
- Интеграция в model-discovery (как Ollama)

**Provider preset:**

```typescript
llamacpp: {
  name: 'llamacpp',
  label: 'Local llama.cpp',
  base_url: 'http://127.0.0.1:8080/v1',  // default llama-server port
  api_key_env: 'LLAMACPP_API_KEY',       // optional, can be empty
  api: 'openai',                          // OpenAI-compatible
  defaultModel: 'llama-3.2-1B-Q4_K_M.gguf',
}
```

### 3.2 Model Catalog (НОВОЕ)

```
src/utils/model-catalogue.ts
```

**Содержимое:**

- Список моделей: название, размер, quant, recommended RAM, recommended VRAM, context size, TPS estimate
- `getRecommendedModel(systemInfo)` → лучшая модель под систему
- Категории: fast/generation/long-context/low-vram/high-quality
- Формат: JSON или YAML, может обновляться отдельно от кода

**Пример entry:**

```yaml
- name: llama-3.2-1B-Q4_K_M.gguf
  size: 0.7GB
  quant: Q4_K_M
  minRAM: 2GB
  minVRAM: 512MB
  context: 8k
  tps: 30-50
  category: fast
  recommended: true # для систем < 8GB RAM
```

### 3.3 CLI ↔ Desktop Unified Config

**Проблема:** сейчас у CLI и Desktop разные конфиги, данные не синхронизируются.

**Решение:**

```
~/.config/argentum/
├── config.yaml        # Основной config (все платформы)
├── providers.yaml     # API keys (encrypted)
└── workspace/
    ├── memory.db
    ├── sessions/
    └── features/
```

**CLI:** `~/.config/argentum/config.yaml`
**Desktop:** тоже `~/.config/argentum/config.yaml` (portable)

**Миграция:** при первом запуске desktop предлагает импортировать существующий workspace.
