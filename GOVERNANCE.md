# Project Governance

Argentum is a single-maintainer project led by AG064 (GitHub).

## Decision Making

All final decisions about the project are made by the project maintainer. This includes:

- Accepting or rejecting contributions
- Setting project direction
- Approving releases
- Resolving disputes

## Roles

**Maintainer** — AG064 (agdroke064@gmail.com)

- Sole decision-maker for the project
- Reviews all contributions
- Manages releases and versioning

## Contribution Process

1. Open an issue to discuss major changes before writing code
2. Fork the repository and create a branch for your changes
3. Submit a pull request to the development branch
4. The maintainer reviews and decides whether to merge

## No Formal Committee

This project does not have a steering committee or other governance body. All decisions rest with the single maintainer.
