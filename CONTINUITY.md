# Access and Continuity

## What Happens If the Maintainer Is Unavailable

Argentum is a single-maintainer project. In the event that the maintainer (AG064) is unable to continue:

### GitHub Repository

The GitHub repository at https://github.com/AG064/argentum remains publicly accessible. The repository can be transferred to a new maintainer through GitHub's standard transfer process.

### Source Code

All source code is open source and publicly available. Anyone can fork the repository and continue development independently.

### Releasing

The project uses standard npm and GitHub release process. A new maintainer with access to the repository can:

- Create releases using `npm run release`
- Publish to npm if needed
- Manage GitHub releases

### Taking Over Maintenance

To take over maintenance:

1. File a GitHub issue requesting transfer of repository ownership
2. If no response within 30 days, GitHub's account recovery process may apply
3. For security disclosures, contact agdroke064@gmail.com

### Limitations

This project does not have a formal succession plan or duplicate access credentials. The nature of a single-maintainer OSS project means some interruption is possible if the maintainer becomes unavailable. However, the open-source license ensures the code remains available for community use and continuation.
